# Kampüs Etkinlik ve Kulüp Rehberi

## Proje Amacı
Üniversite öğrencilerinin kampüsteki kulüp faaliyetlerini ve atölyeleri kolayca keşfetmesine yardımcı olmayı amaçlar. Ziyaretçiler üç sayfalık ortak menü üzerinden etkinlik listesine ulaşabilir ve etkinlik başlıklarına göre anlık arama yapabilir.

## Proje Dosyaları
- `index.html`: Site adı, hedef kitle, kısa tanıtım ve etkinlik listesine yönlendiren bağlantı.
- `etkinlikler.html`: Beş özgün etkinlik kartı ve başlığa göre canlı arama/filtreleme arayüzü.
- `hakkimizda.html`: Konunun seçilme gerekçesi ve sitenin ziyaretçiye sağladığı fayda.
- `style.css`: Tüm sayfalarda ortak kullanılan responsive (390 px uyumlu) tasarım kuralları.
- `script.js`: Arama kutusuna yazıldıkça yalnızca başlıkları filtreleyen, sayaç ve boş sonuç mesajını güncelleyen JavaScript kodları.
- `AI_NOTLARI.md`: Yapay zekâ destekli geliştirme sürecinde kullanılan promptlar ve kod açıklamaları.
- `TEST_NOTLARI.md`: Altı test senaryosunun girdi, beklenen sonuç ve gerçekleşen sonuç kayıtları.

## Çalıştırma Adımları
1. Repository dosyalarını bilgisayarınıza indirin veya GitHub Codespaces üzerinde açın.
2. `index.html` dosyasını herhangi bir modern web tarayıcısında (veya VS Code Live Server ile) açın.
3. Üst menüden **Etkinlikler** sayfasına geçerek arama kutusu üzerinden etkinlik başlıklarını filtreleyin.
