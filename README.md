* **Öğrenci Numarası:** 25015221039

## Projenin Amacı
Bu proje, BPR201 İnternet Tabanlı Programlama dersi kapsamında GitHub Codespaces ve yapay zekâ araçları desteğiyle geliştirilmiş en az üç sayfalık bir kampüs etkinlik web sitesidir[cite: 1, 3].

## Sayfalar
1. **Ana Sayfa (`index.html`):** Site başlığı, kısa tanıtım ve diğer sayfalara yönlendirmeler[cite: 1].
2. **Etkinlikler (`etkinlikler.html`):** En az beş özgün etkinlik kartı ve JavaScript tabanlı anlık arama / filtreleme özelliği[cite: 1, 3].
3. **Hakkımızda (`hakkimizda.html`):** Projenin/topluluğun tanıtımı ve amacı[cite: 1].

## Çalıştırma Adımları
1. Projeyi GitHub'dan ZIP olarak indirin veya klonlayın[cite: 2].
2. `index.html` dosyasını tarayıcınızda açarak siteyi görüntüleyin.
